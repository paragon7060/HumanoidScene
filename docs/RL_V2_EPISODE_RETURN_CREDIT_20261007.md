# 실제 종료 경로의 누적 보상으로 Q 학습 보강

성공 동작 유지 SAC의 전체 개발 평가 흐름은 **23→25→23→33→21/128**이었다.
마지막21건은 중간 좌9·우8, 상단 좌4·우0이다. 최고33건 정책은 별도로
보존했지만 상단 오른쪽과 안정적인 일반화는 아직 해결되지 않았다.
[마지막 전체 평가·동일 모델 확인](assets/rl_v2_servo_retention_final_full_DEV_20261007.json).

그대로 오래 학습한 모델을 최고 모델과 혼동하지 않는다. 동일한128개 요청
조건을 반복했지만 flap 추첨과 reset 물리가 완전히 같다고 가정하지 않으며,
초기화 실패도 분모에 유지한다. 마지막 평가의 공통 유효116조건에서는
초기23→18건이었다. 이는 개발 평가이고 독립 FINAL 평가는 아직 사용하지 않았다.

## 새 비교에서 바꾸는 부분

`--measured-train-credit measured-episode-return`을 선택형으로 추가했다.
기본 one-step SAC와 기존16스텝·종료25% 비교의 동작은 유지한다.

| 항목 | 새 설정 |
| --- | --- |
| 시작 actor | 최고33/128 모델의 실제 동작만 복사, 원본 actor3126/Q14550 |
| Q·optimizer·모든 보상 은행 | 새로 시작, 이전 보상 라벨이나 평가 전이를 가져오지 않음 |
| critic 보조 목표 | 자기 TRAIN에서 실제 끝난 경로의 할인 누적 보상 |
| 종료 이후 Q bootstrap | 없음, 실제 마지막 성공·실패·시간 초과 보상까지 계산 |
| 할인율 / 가중치 / 보조 배치 | 0.999 / 0.1 / 64개 |
| 표본 선택 | 구역 균형 → 경로 균등 → 경로 안 동작 균등 |
| 시간 관측 | actor518 유지, critic578에 실제 task 잔여 시간 추가 |
| 성공 동작 유지 | 기존 실제 servo 명령 구간 손실0.01 유지 |
| 환경 보상 | 기존 성공+8 및 다른 가중치 유지 |
| 낙하 판정 | 새 Q·빈 은행에서 시작하며 reset 상대10cm 사용 |

완료된 경로의 보상 `r`에 대해 `G_t = r_t + 0.999 G_(t+1)`, 마지막은
`G_T = r_T`다. Q 보조 손실의 목표는 이 실제 `G`이며 예측 Q를 더하지 않는다.
성공 경로와 실패 경로를 모두 사용한다. 경로를 먼저 균등하게 뽑아 오래
지속된 시간 초과 경로가 길이 때문에 표본 대부분을 차지하는 것을 줄인다.

이 목표는 수집 당시 행동의 실제 누적 보상이다. 중요도 보정이 없으므로
현재 정책의 불편 추정값이라고 주장하지 않는다. 중간 엔트로피도 더하지 않는다.
환경의 즉시 보상·온라인 replay 라벨·기존 one-step 목표를 소급 수정하지 않는다.
옵션과 은행 계약이 다른 체크포인트의 재개는 거부한다.

박스·base·배경·단단한 동적 flap 무작위화, 양손 실제 pad5N 파지·0.25초
유지·지지면에서8mm 들기, 랙10N·주변 장애물5N, 자기 충돌OFF를 유지한다.
박스 고정이나 curriculum은 추가하지 않았다. Base 접근은 제어기가 담당하고
SAC가 접근 후 양팔·상체·gripper 파지를 조정한다.

SAC supervisor는 --robot-model/--gripper를 실제 runner에 전달하며 mobile/flap
launcher는 모델 기본값 이후 CLI override를 받는다. prepared pose는 model별로 선택된다.

실제 runtime에 `[GRAVITY] ON: 18 body/arm joints` 출력 확인. 이는 PhysX force drive
목표에 g/Kp를 더하며 논리 targets와 effort cap을 유지한다. floating root 및 box
payload 보상은 지원하지 않는다. source는 고정 복사이고 assets는 원본 directory에
symlink되므로 향후 assets pull/편집은 이 실행에 영향을 줄 수 있다.

최소 CPU 확인: gravity/model/mobile config/claw assets/initial states 테스트 35개 통과.
실제 실행/종료/업로드 완료 여부는 parent/status.json과 metrics.jsonl을 확인한다.
명령 전체와 source hash는 latest_sac_s63_leju.json, parent/launch.json,
source/source_manifest.json에 저장했다.

사용자가 action space 증가에 따른 학습 기간 확장을 요청해 예산을 1500에서 6000
iteration으로 변경했다. 초기 실행은 warmup iteration 7까지만 수행했으며 optimizer
update는 0회였다. 초기 learner는 종료 요청 뒤 Isaac 종료에서 지연되어 기존
supervisor가 120초 후 자기 child group만 SIGKILL했다 (exit -9). 이전 learner가
실제 종료한 뒤 새 실행을 시작했고, 초기 실행의 종료 로그와 metadata는 Drive
최종 checksum 검증까지 완료했다. 삭제/종료 대상에 다른 사용자 작업은 포함되지 않았다.

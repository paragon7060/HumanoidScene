# GPU 3 SAC 새 학습 — 2026-09-11

사용자가 새 파일의 task 조건 그대로 실행하는 데 동의한 뒤 시작했다.
오른팔만 제어하고 두 후보 flap의 표면을 대상으로 한다. 왼팔은 고정하며
충돌 종료·벌점은 비활성화다. 물리 충돌과 센서는 유지한다. Curriculum은 없다.
따라서 이 실행의 unsafe rate가 0이어도 충돌이 없다는 뜻이 아니다.

## SAC 호환성 검토

- Actor/critic/replay/관측 정규화는 실제 환경의 관측·action 차원으로 생성한다.
  오른팔 7관절 + gripper 1개 구성에 별도 네트워크 수정은 필요하지 않았다.
- Entropy 목표도 action 차원에서 계산하므로 오른팔 action 수에 맞춰진다.
- 새 reaching/alignment/lift 이력과 grasp credit 관측은 일반 관측 벡터로 저장한다.
  Pre-reset next observation과 settling 이전 action 마스크 처리를 유지한다.
- 관련 CPU 테스트 33개가 통과했다. 별도 Isaac 평가 실행 없이 본 학습을 시작했다.
- 관측·action·보상 계약이 바뀌었으므로 이전 checkpoint를 재개하지 않는다.
- 준비 후 추가된 `configure_flap_ppo`와 PPO 상태 기록 변경도 소스에 포함했다.
  이 설정은 PPO용이며 SAC의 actor/critic/optimizer를 교체하지 않는다.

공통 보상의 반복 획득 가능성은 `GIT_REPULL_REVIEW_20260911.md`에 기록되어 있다.
이번 실행은 승인된 현재 보상을 사용한다. SAC 필수 호환성 수정이 없다는 판단은
그 보상의 성능이나 반복 보상 경로가 해결됐다는 의미가 아니다.

## 실행 설정

| 항목 | 값 |
|---|---|
| GPU | CUDA_VISIBLE_DEVICES=3, 내부 cuda:0, renderer 물리 GPU 3 |
| 환경 | 4096 |
| Replay | CUDA에 36,000,000 transition, checkpoint에는 미포함 |
| 예산 | 예상 약 72GiB, 자체 사용 상한 76GiB, GPU 전체 여유 하한 4GiB |
| Warmup | 실제 행동 가능한 transition 2,000,000개, 최소 450 유효 vector step 환산 |
| Batch / updates / rollout | 1024 / 4 / 16 |
| 종료 기준 | 1500 iteration, 최대 실행 86400초 |
| 저장 | 50 iteration 간격 및 정상 종료 시 |
| 백업 | 설정된 Drive remote, 300초 간격 |

크기·MD5 검증을 마친 오래된 checkpoint만 정리하며 최신 2개와 최신 검증본 2개를
보호한다. 종료 후 닫힌 로그도 업로드·검증한다. 기존 인증을 새로 만들거나 복사하지 않았다.

# S63 몸통·양팔 보정 시간을 줄이는 계획

실물 VR 기록과 첫 sim replay까지 완료된 뒤의 최신 제어 구조·계산량·수용 기준은
[S63 real-like control 보정 계획](S63_REAL_LIKE_CONTROL_CALIBRATION_PLAN.md)을 따른다.
이 문서의 실물 시험 설계는 이력과 보조 검증 계획으로 유지한다.

대상은 기본 S63 + Leju twofinger다. Gripper 보정은 별도 작업의 결과를 받아 통합한다.
다른 로봇 모델에는 절차를 재사용하되 S63 실측 파라미터를 그대로 복사하지 않는다.
이 문서는 추가 시험 설계이며 새로운 실물 명령을 실행한 결과가 아니다.

프로젝트의 VR teleop은 Isaac 전용이며 실물 자세 전환 수단이 아니다. 기존 VR로 실물 B/C를 준비한다는 안내는 잘못된 경로 가정으로 철회했다. 큰 실물 기준 자세 전환은 별도 보정 명령 경로에서 설계·검증해야 하며 아직 준비되지 않았다. A 기준의 읽기 전용 기록과 기존 소각도 실물 시험은 이와 독립적으로 유효하다.

사용자는 별도의 실물 Quest 앱 `kuavo_hand_track_MR`로 기존 controller VR 모드에서 조작할 수 있다. 현재 다음 단계는 [실물 VR 명령·상태 기록](REAL_VR_RESPONSE_CALIBRATION.md)이다. 사람이 컨트롤러를 고정하지 않고 실물 VR 입력, 제어기/모터 명령과 센서 상태를 읽기 전용으로 수집한 뒤 같은 실물 입력을 sim에서 재생·비교한다. [Isaac VR 기록/후보 생성](VR_JOINT_RESPONSE_CALIBRATION.md)은 보조 도구이며 실물 VR 입력 기록을 대체하지 않는다.

## 현재 데이터와 재시험 범위

- 왼팔 4번: ±0.25° static 및 3회 반복 성공. 정지 오차는 +방향 약 −0.035~−0.038°, −방향 약 −0.012°로 반복성이 확인됐다.
- 13관절 단축 시험은 약 185초에 연결 감시로 중단됐다. 기록 파일은 real_robot_calibration/s63_body_arms/data/timing_fix_20260915_234217/run_20260915_234345.jsonl이다.
- 완주한 11개: 오른팔 4번, 왼팔 1·2·3·5·6·7번, 오른팔 1·2·3·5번. 완주한 구간만 분석에 사용하며 전체 시험 성공으로 표시하지 않는다.
- 오른팔 6번은 양의 이동·복귀까지 기록됐으나 음의 시험이 없다. 오른팔 7번은 미시험이다.
- 당시 이전 왼팔 4번까지 포함하면 팔 14개 중 12개를 완료했다. 이후 사용자 실행 `right_finish_20260916_000940_712000453/run_001211.jsonl`에서 오른팔 6·7번 34초 시험이 정상 종료되어 팔 14개 시험 구간을 모두 완료했다.
- 현재 11개 관절은 전체 정지 비교 표본이 유효하다. 왼팔 3·7번과 오른팔 4번은 일부 구간 표본이 부족하다. 오른팔 6번은 실측 복귀 변화 약 −0.132°로 대표 응답 확인이 필요하다. 마지막 모터 목표는 기준에 일치했다.
- 오류 직전 마지막 목표는 기준 자세였다. 그렇더라도 오류 후 실물 정지를 확인하고 재캡처해야 한다.
- 중단은 센서 수신이나 목표 loop stall 오류가 아니다. 기존 메시지는 EOF·신호·heartbeat 지연을 구분하지 못하므로 원인은 미확정이다. 앞으로 오류 행에 stop 요청/원인, heartbeat age, 기록 오류를 남긴다.

13관절 전체를 재실행하지 않는다. 미완료 오른팔 보완은 끝났으며, 이제 대표 4개 관절만 추가 응답을 측정한다. 데이터 보존을 위해 새 세션과 새 로그 이름을 사용한다.

## 시간 예산

추가 실물 점유는 대략 20분, 준비와 자세 변경 여유를 포함해 25분을 목표로 한다.
실물 자세 이동과 하중 부착 시간은 현장 조건에 따라 달라진다. 확인되지 않은 자세나 하중을 시간에 맞추려고 강행하지 않는다.
드라이버 단위 확인, 로그 분석, sim replay는 로봇을 움직이지 않고 먼저 수행할 수 있다.
현재 도구로 실행 가능한 시험과 별도 자세 준비가 필요한 시험을 구분한다.

| 단계 | 추가 실물 점유 예산 | 측정 범위 | 다음 단계 기준 |
|---|---:|---|---|
| 0. 기존 자료 분석·제어 의미 확인 | 0분 | 완료한 팔 12개, gain/torque 출처, 시간 정렬, sim 명령 replay | 비교 가능한 채널과 식별 가능한 값 확정 |
| 1. 선별 검사 마무리 | 약 1분 | 오른팔 6·7번만 ±0.25°, 이동 2초/정지 2초 | 정상 복귀와 유효 로그 |
| 2. 대표 관절 응답 | 약 4분 | 추가 측정 필요 관절 최대 4개, 저속 1회 왕복 | 방향 차이·지연·정착·복귀를 sim과 비교 가능 |
| 3. 대표 자세의 중력·하중 | 약 8분 | 계획한 6개 정지 조건 | 정착한 구간과 유효 effort 또는 q 기반 하중 민감도 |
| 4. 몸통 응답 | 약 3분 | waist_pitch/yaw 개별 작은 움직임 | 팔·몸통 반응과 복귀 비교 가능 |
| 5. 별도 조건 검증 | 약 4분 | 학습에 쓰지 않은 자세/속도/하중 2~3조건 | 모델 조정이 다른 조건에서도 개선되는지 확인 |

20분은 1차 free-space 보정 자료 수집 예산이다. 전 범위 inertia 식별, wheel 이동 및 conveyor 접촉 시험까지 완료한다는 의미가 아니다.
기존 데이터를 먼저 검토해 추가 응답 측정이 필요 없는 관절은 단계 2에서 제외한다.

## 0. 기존 로그로 먼저 처리할 검토

1. 논리 목표 → quick 목표 → 필터/WBC 입력 → joint_cmd → 센서를 구분한다. 필터 지연과 관절 응답을 섞어 gain으로 보정하지 않는다.
2. ROS header와 원격 receipt 시각의 차이·주기·누락을 확인한다. 같은 시간축인지 확인하기 전에는 receipt 차이를 순수 모터 지연이라고 해석하지 않는다.
3. 느린 선별 검사에서는 가까운 motor command와 measured q를 짝지어 추종 오차를 계산한다. 짝 간격 50ms 초과 데이터는 동적 비교에서 제외한다. 정지값만은 같은 plateau 안의 동일한 전체 명령 두 표본이 300ms 이내로 bracket할 때 추가 사용할 수 있으며 그 수를 별도로 보고한다. 지연 추정에는 사용하지 않는다.
4. 2초 hold는 마지막 0.75초를 사용한다. 그 구간이 여전히 정착 중이면 해당 관절의 정지값을 확정하지 않고 그 관절만 5초 hold로 추가 측정한다.
5. 각 관절의 초기·정방향·역방향·최종 정지 평균, 방향 차이, ramp 최대 오차, 복귀 변화, 로그 간격을 산출한다.
6. 정지 추종 오차는 encoder zero라고 부르지 않는다. 영점 보정에는 외부 pose 또는 알려진 기준이 필요하다.
7. 이미 기록된 WBC/모터 gain을 목록화한다. 실제 register 단위·기어비·출력 토크 변환은 읽기 전용 자료로 확인하며, 모터 설정은 변경하지 않는다.

연결 오류는 추가 물리 시험 전에 별도 확인한다. 30초 timing 검사는 장시간 heartbeat 신뢰성을 보장하지 않는다.
새 오류의 stop_reason/heartbeat_age와 로컬 종료 기록을 비교하고, 필요한 경우 분석 작업 중 4분 읽기 전용 record로 stdout/heartbeat 경로를 재현한다.
이 검사는 목표 publisher나 모드 서비스를 사용하지 않으며 추가 실물 움직임을 요구하지 않는다.
오류를 재현하면 연결/로컬 기록 원인을 먼저 해결한다. heartbeat 제한을 늘리거나 전체 물리 시험을 반복해 진단하지 않는다.

2026-09-16 확인: 읽기 전용 record에서 heartbeat age 1.022초로 중단이 재현됐다(EOF·신호 요청 및 기록 큐 오류 없음). 로컬 고속 로그의 중복 JSON 파싱/매 행 flush를 줄이고 heartbeat sequence·양쪽 간격을 추가 기록했다. 수정 후 `data/connectivity_retry_20260915_235648/record.jsonl`은 240.012초 `summary ok=true`로 완료됐다. 1213개 heartbeat가 송수신됐고 최대 전송 간격 0.2003초, 최대 수신 간격 0.5107초, write 오류 없음이었다. 이 한 번의 통과로 장시간 실물 제어 안정성이나 앞선 지연의 정확한 원인이 확정되지는 않는다.

기존 로그의 관절별 결과는 [선별 분석 보고서](../real_robot_calibration/s63_body_arms/reports/screen_20260915.md)에 있다. 완료 12개 중 9개는 전체 정지 구간의 비교 표본이 유효하고, 왼팔 3·7번과 오른팔 4번은 일부 표본을 보완한다. 추가 응답 후보는 왼팔 5·7번과 오른팔 1·5번이며 최대 4개로 제한한다.

오른팔 보완 이후 [최신 결과](../real_robot_calibration/s63_body_arms/reports/screen_20260916.md)는 팔 14개 구간 완료/11개 전체 정지 표본 유효다. 대표 4개 우선순위는 오른팔 6번, 왼팔 5번, 오른팔 5·7번으로 갱신했다. 최대 방향별 보정 오차 약 0.206°, 0.189°, 0.160°, 0.154°를 근거로 했다. 첫 응답 계획은 ±0.5°, ramp 4초/hold 3초, 총 115초이며 목표 최대 속도는 앞선 ±0.25°/2초와 같은 0.2344°/s다. 왼팔 7번은 표본 보완으로 남고 오른팔 1번은 경계값으로 후순위다.

이후 30초 읽기 전용 check는 로컬 전송 간격이 0.2002초로 정상인데 원격 heartbeat 수신이 1.015초 지연되어 실패했다. 당시 원격 센서·모터·IMU와 50Hz 검사 루프는 계속 갱신됐다. SSH 압축만 적용한 record도 실패했다. 무선만 가능한 현장에서 로봇과 노트북의 Wi-Fi 절전을 임시 해제했다. 이후 로봇 off 240초 record(도중에 노트북도 off)와 양쪽 off 새 계획 30초 timing 검사는 성공했다. 최대 control gap은 22.12ms였다. 모터·ROS 설정이나 중단 기준은 변경하지 않았다. 장시간 안정성과 정확한 원인은 미확정이며, 상세 결과는 [연결 진단](../real_robot_calibration/s63_body_arms/reports/connection_20260916.md)에 기록한다.

추가 측정 후보는 초기 bias를 뺀 endpoint 오차나 측정 자세 복귀 변화가 **max(0.1°, 초기 반복성의 3배)**를 넘는 관절부터 고른다.
이는 잠정적인 추가 측정 기준이며 안전 한계가 아니다. 좌우 차이가 크거나 정착하지 않는 관절도 후보에 넣되, 우선 최대 4개만 측정한다.
논리 목표와 motor/WBC 목표 자체가 다른 경우에는 물리 gain보다 제어 경로·필터를 먼저 검토한다.

### effort 단위가 해결되지 않을 때

드라이버 자료 확인은 먼저 시간 제한을 두고 수행한다. 해결되지 않으면 제조사 확인 항목으로 남긴다.
q_cmd/q만으로 equivalent 폐루프 응답·방향성·하중 민감도를 맞추는 작업은 진행할 수 있다.
그러나 실제 motor Kp/Kd, 출력축 마찰·질량·COM이 각각 식별됐다고 주장하거나 해당 숫자를 임의로 확정하지 않는다.
joint_cmd.tau는 요구 토크이며 독립적인 실측 토크가 아니다. joint_torque도 출처와 단위 검증이 필요하다.

## 1~2. 작은 움직임은 반복 수보다 정보량을 늘린다

- 미완료 오른팔 6·7번은 현재 도구의 static, ±0.25°, ramp 2초/hold 2초로 한 번에 순차 실행할 수 있다. 계획 시간은 34초다.
- 대표 관절은 팔별로 적어도 하나를 포함하고, 큰 추종 오차·방향 차이가 있는 관절을 우선한다.
- 첫 확대는 ±0.5°, 필요하고 공간·관절 제한이 확인되면 최대 ±1°다. 현재 도구의 팔 상한도 ±1°다.
- 확대 시험은 ramp 4초/hold 3초, 양방향 1회로 한다. 최대 목표 속도는 ±1°에서 약 0.469°/s다.
- 4개 관절의 계획 시간은 115초다. 여유가 없거나 필요한 관절이 2개면 59초로 줄인다.
- 3회 반복은 결과가 불안정한 관절에만 추가한다. 차이가 없는 관절은 재시험하지 않는다.
- 팔 시험은 한 관절씩 움직이고 나머지 몸통·팔 논리 목표는 기준으로 유지한다.

동일한 명령을 sim에 replay해 초기 bias, 지연/필터, 정착, damping을 먼저 맞춘다.
gain을 움직일 때마다 다른 값으로 바꾸는 실물 시험은 하지 않는다.
±1°로 확대해도 전체 관성·중력 모델이 식별되는 것은 아니다.

현재 대표 ±0.5° 시험은 사용자 실행에서 정상 종료했다. 명령 극점 차이 1°에 대해 실측 차이는 왼팔 5번 0.918°, 오른팔 5번 0.867°, 오른팔 6번 0.638°, 오른팔 7번 0.632°였다. 왼팔 5번 실측 복귀 변화 약 −0.153°도 남았다. [응답 결과](../real_robot_calibration/s63_body_arms/reports/response_20260916.md)를 바탕으로 방향성·추종을 비교한다. 다음 우선순위는 서로 다른 안전한 기준 자세의 정지 기록이다. ±1° 국소 확대는 추가 응답 자료가 필요한 관절에만 고려하고 자동으로 전체 관절을 재시험하지 않는다.

## 3. 중력은 소수의 서로 다른 자세에서 측정한다

같은 자세 주변의 작은 왕복을 여러 번 하는 대신 다음 조건을 준비한다.

| 조건 | 내용 | 용도 |
|---|---|---|
| A | 현재 기준 자세, 무부하 | 기존 로그 활용 및 기준 |
| B | 확인된 안전 범위의 팔 굽힌 자세, 무부하 | 다른 관절 조합의 정적 응답 |
| C | 확인된 안전 범위의 팔 전방 자세, 무부하 | 다른 중력 lever arm |
| D | B와 같은 자세, 질량이 알려진 작은 하중 | 하중 차분 |
| E | C와 같은 자세, 같은 하중 | 자세에 따른 하중 효과 |
| F | fitting에 쓰지 않은 자세 | 일반화 검증 |

각 조건에서 정방향/역방향 접근 후 8초 기록하고, 실제로 정착한 마지막 3초를 비교한다.
A의 유효 기존 데이터는 재사용한다. B/C는 확인된 작업 공간 안의 자세이며 최대 팔 뻗기나 새로운 위험 자세를 요구하지 않는다.
양방향 접근은 안전한 작은 offset으로 수행할 수 있지만, 큰 기준 자세 변경은 현재 ±1° 시험 도구로 자동 생성되지 않는다.
검증된 실물 조작 경로로 자세를 준비한 다음 그 입력을 중지하고 새 capture/hold 계획을 만들어야 한다.
기준 자세를 바꿀 때마다 IMU 기준도 재캡처하며 옛 capture를 재사용하지 않는다.

알려진 하중은 지지·고정과 부착 위치까지 기록한다. Gripper 보정 중인 장치를 동시에 조작하지 않는다.
출력 effort가 유효할 때만 nominal mass/first moment/payload 또는 작은 identifiable parameter set을 fit한다.
effort가 미검증이면 CAD 기반 nominal gravity를 유지하고 자세별 추종/하중 민감도와 오차 범위만 산출한다.
하나의 정지 오차를 중력 토크 또는 질량 오차로 바로 바꾸지 않는다.

## 4. 몸통과 이후 시험의 범위를 제한한다

- waist_pitch/yaw는 우선 ±0.25°, ramp 4초/hold 3초, 한 관절씩 1회로 한다. 두 관절 계획 시간은 59초다.
- knee/leg는 관절 제한과 높이·무게중심 영향 때문에 별도 시험으로 남긴다. 현재 knee 기준 약 0.3745°는 양방향 시험의 URDF 0.5° margin을 충족하지 않을 수 있다. 제한을 완화해 실행하지 않는다.
- 현재 목표가 stationary body + arms라면 knee/leg 동적 식별과 wheel 이동은 1차 보정 완료 조건에서 제외하고 배포 범위에 명시한다.
- 실제 body/base 이동을 포함한 RL을 배포하려면 knee/leg와 wheel 응답·slip/odometry 검증은 추가 완료 조건이 된다.

현재 물리 중단 기준(추종 오차, 속도, IMU, 0.2초 stall, 1초 heartbeat)과 제어권 검사는 시간을 줄이기 위해 완화하지 않는다.
시험 중 다른 사람의 조작은 허용하지 않으며, 로봇 정지는 실물 정지 수단으로 수행한다.

## 5. 적합보다 검증을 먼저 끝내는 최소 모델

1차 목표는 실물과 같은 논리 q/v 목표 경로의 폐루프 응답을 sim에서 재현하는 것이다.
기존 WBC와 motor loop의 서로 다른 gain을 Isaac stiffness/damping에 그대로 복사하지 않는다.
sim solver의 중력 보정 target bias를 실물로 보내거나 WBC torque에 중력을 다시 더하지 않는다.

처음에는 delay/filter, effective response, 정지 bias/방향성, nominal payload의 작은 집합만 조정한다.
실물 데이터에 없는 mass/inertia/마찰을 동시에 fit해 같은 오차를 여러 파라미터로 설명하지 않는다.
보정에 쓰지 않은 자세·속도·하중에서 joint/TCP 오차와 복귀가 개선됐는지 확인한다.
허용 오차는 작업 요구와 실물 반복성을 기준으로 정하며, fitting error가 낮다는 이유만으로 통과시키지 않는다.

## 별도 단계로 남길 작업

| 항목 | 먼저 할 검토 | 추가 실물 시험 조건 |
|---|---|---|
| 관절 zero/TCP/hand-eye | URDF 축·순서·mount, 외부 기준 측정 계획 | 알려진 기준/외부 pose가 있을 때 여러 자세를 묶어 측정 |
| Gripper | 다른 작업의 LUT·방향 차이·질량/패드 결과 통합 | 같은 시험을 중복하지 않음 |
| 박스/flap/conveyor | 치수·질량·힌지·패드·belt 속도를 실제 task와 일치 | arm 응답과 Gripper 결과가 준비된 뒤 동일 task에서 slip/lift/placement를 함께 기록 |
| wheel 이동 | 현재 root 직접 이동과 실물 wheel controller 차이 확인 | 이동을 포함한 배포가 필요할 때 별도 저속 시험 |
| inertia/armature | 기존 로그의 식별 가능성 평가 | 관성이 작업 오차의 원인이고 effort가 유효할 때 속도·가속도를 다양화 |
| RL 관측·주기 | 실물에서 얻을 수 없는 truth 제거/critic 분리, noise/age, policy 적분 주기 일치 | 실물 policy 실행 전 필수이며 모터 시험을 추가한다고 해결되지 않음 |

이 작업을 모두 끝내기 전에는 전체 real-to-sim 보정 완료라고 표시하지 않는다.
1차 결과에는 검증한 모델/자세/하중/속도/관절 범위와 미확정 항목을 함께 기록한다.

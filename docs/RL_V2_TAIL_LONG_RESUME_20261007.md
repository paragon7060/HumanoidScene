# 네 위치에서 파지한 SAC를 이어 학습하기

파지 직전 성공 표본을 늘린 SAC의 마지막 전체 DEV는 **19/128**이었다.
구역별 성공은 중간 좌7·우6, 상단 좌3·우3이다. 자신의 초기23/128을 넘지
못했고 대표30/128보다도 낮다. 다만 초기0이던 상단 오른쪽에서 실제 안전한
양손 파지·0.25초 유지·8mm proof lift 성공3건을 확인했다. 다른 구역의 성능을
잃지 않고 더 일반화할 필요가 있어 같은 정책의 장기 추가 학습을 준비했다.

## 전체 결과와 성공 조건

| 구역 | 같은 실행의 초기 성공 /32 | 마지막 학습 후 성공 /32 |
| --- | ---: | ---: |
| 중간 왼쪽 | 12 | 7 |
| 중간 오른쪽 | 6 | 6 |
| 상단 왼쪽 | 5 | 3 |
| 상단 오른쪽 | 0 | 3 |
| 전체 | 23 /128 | 19 /128 |

최종 실패는 랙58·박스 낙하18·시간 초과32·초기화 무효1이었다. 원래128요청,
구역별32개와 초기 무효 분모를 유지했다. 동일 actor4337·Q19396 모델을 평가가
끝나기 전에 보존했다. 전체 성공 흐름은 **23→14→22→13→19/128**이다.
마지막에 상단 오른쪽이 개선된 사례가 있지만 안정적인 일반화나 전체 개선으로
단정하지 않는다. 반복 DEV는 독립 FINAL이 아니다.
[전체 평가·실제 접촉·유지·들기 근거](assets/rl_v2_tail64half_final_full_DEV_after1536_20261007.json).

상단 오른쪽의 성공은 env7·15·67, 원래 seed121301·121303·121316이다.
Base의 기준 위치 대비 초기 좌우 이동은 −0.90·+2.54·−3.19cm, 바깥 이동은
8.87·8.75·9.97cm, yaw는 −0.46·+0.39·+4.04°였다. Box도 고정하지 않았다.
Base는 무작위 초기 위치에서 별도 접근 제어기로 작업 위치까지 이동한 뒤
유지하고, 학습한 팔·상체·그리퍼가 파지한다. 세 사례를 전체 범위의 안정적
성공률로 해석하지 않는다.

## 이어 학습하는 방법

종료된 같은 CPU 물리 SAC의 actor4337·Q19396, 네 optimizer와 실제 replay
500,000행을 보존한다. 성공 은행26경로·12,300행에는 상단 오른쪽 TRAIN 성공
2경로도 있으며, 성공·실패 n-step 은행도 그대로 복원한다. 실제 full trainer에서
모든 model·optimizer tensor와 greedy 목표가 같고 계약이 엄격히 일치함을 확인했다.
[실제 전체 trainer 복원](assets/rl_v2_tail19_long_resume_full_restore_20261007.json).

추가 TRAIN은 **3,072조건·24개 wave**다. 이전1,536조건을 합하면4,608조건이며,
다른11개 계획과 seed가 겹치지 않는다. 최초 및 TRAIN3개 wave마다 원래 DEV128을
반복해 총33개 wave로 비교한다. 독립 FINAL은 남긴다. Episode의 원래 성공·안전
종료는 유지하고 개발 성능 회귀만으로 전체 추가 학습을 중단하지 않는다.

이 비교는 기존 보상·표준편차0.03–0.12·AR0.99·episode20% 팔 탐색·반경0.30,
actor 성공64표본 중 마지막 구간32표본·Q 성공20→5%·n-step16 보조 손실을
유지한다. 새 종료 보상·작은 잡음·명령 유지·terminal25 설정의 다른 두 비교와
Q나 replay를 섞지 않는다. 두 VR 시연을 실행 중 재생하거나 BC teacher를 추가하지 않는다.

Box/base/주변 박스/단단한 동적 flap의 무작위화·랙10N/장애물5N·양손 실제
접촉·유지·proof lift는 유지한다. Curriculum·박스 고정·성공 조건 완화는 없다.
현재 한 가지 작은 박스·네 위치의 성능이며 다른 크기의 일반화도 아직 미검증이다.

## 실행·저장 상태

현재 입력과 실제 trainer 복원, 고유33-wave 계획 준비를 마쳤다. GPU3에서
기존 두 학습을 유지하며 새 장기 실행을 시작할 준비 중이다. 준비와 복원 검증은
새 실제 학습 시작이나 학습 후 성공률 개선의 증거가 아니다.
초기 checkpoint·계약 metadata7개는 기존 Drive 연결로 크기·MD5를 검증했다.
최소 백업 범위와 기존 장치 검사를 포함한11개 검사가 통과했다.

Replay는 본인 고유 RAM 폴더에 읽기 전용 사본으로 보존했다. 전체 replay의
추가 Drive 전송은 자동 승인 심사에서 명확한 권한이 없다고 거부됐다. 실행은
`--checkpoint-log-backup-only`로 checkpoint·계약·로그만 기존 Drive에 전송한다.
300초마다 크기·MD5 검증 후 오래된 checkpoint만 정리하고 최신2개를 유지한다.
Writer 종료 뒤 로그도 검증한다. 인증이나 공유·다른 사용자 파일/프로세스는 변경하지 않는다.

All 58 upstream files were copied byte-for-byte and checked against their Git
blob hashes. Upstream ROS/Gazebo launch files are preserved as source references;
the Isaac application does not execute them.

`urdf/biped_s63.urdf` is the unmodified official primary URDF.
`urdf/kuavo_s63.urdf` is generated by `scripts/prepare_s63_urdf.sh`: mesh
package paths become relative local paths and wrist visuals select
`l/r_hand_pitch.STL` instead of `l/r_hand_pitch_noHand.STL`. EEF transforms
remain unchanged. Official source meshes may include unused
alternatives; only meshes referenced by the primary URDF are spawned.

`usd/kuavo_s63_fixed.usd` and its configuration layers are Isaac-generated
artifacts, not official manufacturer USDs. Conversion preserves fixed links,
fixes the base and assigns position drives (stiffness 400, damping 40). Camera
sensors configured by the application are separate from this source snapshot.

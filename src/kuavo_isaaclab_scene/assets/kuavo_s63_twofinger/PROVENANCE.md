# S63 + S200062-derived two-finger variant

Generated by scripts/build_s63_twofinger_urdf.py and build_s63_twofinger.sh.
Host: official S63 beta e2da287383c643e923e9594dac2ec86024269737.
Claw: ../leju_claw_two_finger, extracted from S200062.

Official host links/joints, inertia, collision and visual definitions are
preserved, except mesh paths become relative paths and the robot name changes.
No STL files are modified, substituted or hidden. The official S63 source and
its plain USD remain separate and unchanged by this build. Existing wrist
geometry may overlap the newly added claw; the user will visually inspect it.

Mounts use donor xyz left=(0,-0.0005,-0.041), right=(0,+0.0005,-0.041),
rpy=(0,0,0), relative to zarm_l/r7_link. They are not measured S63 mounts.
Both claw/D405 branches retain estimated inertials. Fixed links are kept;
four maximal-coordinate loop-closing hinges finalize the generated USD.
The root is fixed and body position drives use stiffness=400/damping=40;
runtime hand actuator/contact settings come from grippers.json leju-twofinger.

# S63 + S200062-derived two-finger variant

Generated by scripts/build_s63_twofinger_urdf.py and build_s63_twofinger.sh.
Host: official S63 beta e2da287383c643e923e9594dac2ec86024269737.
Claw: ../leju_claw_two_finger, extracted from S200062.

Host input is kuavo_s63/urdf/kuavo_s63.urdf. Both packaged hand_pitch and
hand_pitch_noHand host visuals are accepted before replacing the wrist visual.
The variant preserves this prepared host's links/joints, inertia, collision,
materials and EEF frames. Its wrist visuals use derived
meshes/l/r_hand_pitch_wrist_only.STL: the three disconnected S63 camera/bracket
CAD components (3376 triangles per hand) are removed, leaving the wrist itself.
Only the attached Leju D405 camera and mount remain visible. The builder pins
the source STL hashes and validates component counts before this extraction.
Original STL files and the official biped_s63.urdf remain unchanged.

Mounts use donor xyz left=(0,-0.0005,-0.041), right=(0,+0.0005,-0.041),
rpy=(0,0,0), relative to zarm_l/r7_link. They are not measured S63 mounts.
Both claw/D405 branches retain estimated inertials. Fixed links are kept;
four maximal-coordinate loop-closing hinges finalize the generated USD.
The root is fixed and body position drives use stiffness=400/damping=40;
runtime hand actuator/contact settings come from
../leju_claw_two_finger/config.json; grippers.json only selects that preset.
